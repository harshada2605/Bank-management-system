Technologies Used

Java – Core programming and banking logic.

Java Swing – Creates the desktop user interface.

JDBC – Connects Java with the database.

MySQL – Stores account, user, and transaction data.

Main Features

User Registration & Login – Secure account creation and login.

Account Management – Manage customer account details.

Deposit & Withdrawal – Add or withdraw money from an account.

Balance Enquiry – Check the current account balance.

Fund Transfer – Transfer money between accounts.

Transaction History – View previous banking transactions.

PIN Management – Change and manage account PIN.
