# 🏦 Bank Management System

## 🔐 A Secure & Smart Java-Based Banking Application

The **Bank Management System** is a powerful desktop application designed to simulate real-world banking operations with security, simplicity, and efficiency. It allows users to manage their bank accounts, perform transactions, and track financial activities through an intuitive and interactive interface.

Built using **Java, Java Swing, JDBC, and MySQL**, this system ensures secure authentication, reliable data management, and smooth execution of all banking operations such as deposits, withdrawals, fund transfers, balance enquiry, and transaction tracking.

---

## ✨ Features

* 🔐 Secure User Registration & Login
* 👤 Account Creation and Management
* 💰 Deposit and Withdrawal Operations
* 💳 Balance Enquiry
* 🔄 Fund Transfer Between Accounts
* 📋 Transaction History Tracking
* 🔑 PIN Management and Update

---

## 🛠️ Technologies Used

* ☕ **Java** – Core programming language
* 🖥️ **Java Swing** – Graphical User Interface
* 🔗 **JDBC** – Database connectivity
* 🗄️ **MySQL** – Data storage and management system
